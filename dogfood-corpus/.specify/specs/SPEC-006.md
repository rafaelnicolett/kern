# Saved searches

## Problem

Power users rebuild the same three or four filter combinations every day because there's no way to save a filter set for reuse.

## Requirements

- A user can name and save the dashboard's current filter state.
- Saved searches appear in a dropdown and reapply the full filter state in one click.
- A user can only see and manage their own saved searches, not other team members'.
